# 气泡工坊 · Bubble Studio

选择自己的 PNG，在可视化编辑器中设置点九拉伸线、文字位置、圆角和边框，再应用到 Codex 中你发送的消息。

**目前仅支持 macOS。** 本项目是独立的本机工具；气泡设计 skill 在 [douyinQIPAO](https://github.com/kaitongg-bit/douyinQIPAO) 单独维护。本仓库不打包、不安装 skill，两个项目可以分别更新。

## 第一次运行：不用自己输入命令

需要 Python 3.9+、Node.js 22+，以及已安装的 ChatGPT/Codex 桌面应用。工作台没有 npm 依赖或前端构建步骤。

1. 下载 Releases 中最新 ZIP，解压到一个固定文件夹。
2. 在 **Finder（访达）** 中双击 `Start Bubble Studio.command`，不要在 Codex 文件编辑器里双击。它会打开一个终端窗口并启动本机服务，然后打开工作台。
3. 打开 http://127.0.0.1:19329 。终端里的启动文字是正常日志；代码编辑器里展示的脚本文字不代表已经运行。
4. 点击「连接素材文件夹」，粘贴你原来 PNG 所在的 `outputs` 完整路径；或直接导入 PNG。
5. 选一款气泡，调整预览，保存设置，再点击「应用到 Codex」。

“终端”就是 macOS 自带的命令运行窗口。可以按 `⌘Space` 搜索「终端」或 `Terminal` 打开。通常双击启动脚本就够了，不需要先学终端命令。

### 如果显示 Codex 未连接

先保存正在输入的内容，用 `⌘Q` **完全退出** ChatGPT/Codex，再到浏览器中的工作台点击「启动 Codex 并换肤」。只关闭窗口不等于退出应用。可在 Safari 或 Chrome 打开上述本机地址，避免退出 Codex 后工作台一起消失。

为什么这一步需要用户操作：调试端口必须在桌面应用启动时开启，应用已经运行时无法补上；而当前 Codex 对话本身就在该应用里，自动退出会中断当前工作，因此工具不会替你强制关闭应用。启动命令由按钮执行，你不必手动输入。

如果双击脚本仍未启动，打开终端，输入 `python3 `（末尾有一个空格），把解压文件夹里的 `app/server.py` 拖进终端，再按回车。保持这个终端窗口运行，然后打开工作台地址。若提示缺少 Python 或 Node，先安装所需运行环境。

### 使用源码运行

在终端中逐行执行：

```sh
git clone https://github.com/kaitongg-bit/douyin-codex-bubble-studio.git
cd douyin-codex-bubble-studio
python3 app/server.py
```

## 调整与素材库

- **拉伸线**：拖动四条分割线。拉伸带经过的边框应是平直、连续的横边和竖边，避开弧线、斜线、尾巴、角色和复杂纹理；它们拉长后容易变形。固定角区保留装饰。检查短句、长消息、深色预览后再应用。
- **文字位置**：切换到「文字位置」，拖动蓝色文字框，拖动四角调整大小。界面不要求输入上下左右留白数字。
- **适合聊天**：新素材默认按不超过 240×98 页面像素适配，已有预设不自动覆盖；点击按钮可以重新适配。
- **素材缩放**：可输入 1%–200%。100% 表示原图一个像素对应一个页面像素；200% 放大两倍。比例调整图案和固定边角，文字字号不变；消息变长时气泡继续拉伸。界面会显示原图与基础显示尺寸。
- **圆角与边框**：圆角裁切画布四角，不会重画 PNG 中已有边框。边框沿画布外框描边并跟随圆角；圆角 0 保留原图，边框粗细 0 关闭描边。
- **收起气泡库**：点击库标题旁的箭头收起或展开，编辑与预览空间会随之调整。
- **删除**：点击素材卡片右上角的 ×，PNG 移入 `.local/trash/` 回收区，不是永久删除；点击「撤销最近一次删除」可逐次恢复。原位置有新同名文件时拒绝覆盖。删除当前活动气泡会恢复默认样式；恢复 PNG 后需自行再次应用。

PNG 宽、高各支持 2–4096 px。直接导入单张文件限制 2 MB；连接文件夹读取 PNG 不设这项大小限制。抖音平台上传限制与本工具读取范围不同。编辑不修改 PNG；只有明确点击删除时移动文件。

私人素材、收藏、设置、回收区和日志存放在 `.local/`，已被 Git 排除，公开仓库不包含它们。可用 `BUBBLE_STUDIO_DATA` 指定其他数据目录。

## 想设计新气泡

前往独立的 [抖音气泡设计 skill 仓库](https://github.com/kaitongg-bit/douyinQIPAO)，按其 README 安装 `douyin-chat-bubble`。安装后向 Codex 说：

> 使用 $douyin-chat-bubble 设计一款原创抖音气泡，完成点九结构、镜像、边距和长消息预检，导出 PNG 到我的素材文件夹。

再把 PNG 导入本工作台。「设计新气泡」入口只提供该独立 skill 的链接和可复制的提示，不附带云端生图模型或 API Key。之后更新 skill 只需要更新其自己的仓库，无需同步本项目。

## 连接与恢复

通过仅绑定 `127.0.0.1:19327` 的 CDP 调试端口注入运行时样式，不改官方应用包，不读取聊天文字。九个切片先绘制到同一画布，避免浏览器 border-image 拼接细缝。调试端口对本机其他程序可见；完全退出并正常启动应用可关闭它。

「恢复默认」清空活动气泡并删除运行时样式。工作台运行期间，页面刷新后会重新应用当前气泡。关闭工作台不会删除已经注入的样式；先恢复或完全重启应用。

匹配数反映当前页面挂载的用户消息，切换面板或消息虚拟化时可能为 0。仅 macOS 的 ChatGPT/Codex 桌面端 `app://-/` 窗口经过实机验证，Windows/Linux 当前不支持。应用升级后可能需要适配。本项目不是 OpenAI 或抖音官方插件。

## 验证

```sh
python3 -m unittest discover -s tests -v
node --check app/bridge.mjs
node --check app/static/app.js
```

验证范围见 `VALIDATION.md`。项目包含 `app/` 本机服务、注入桥、可视化编辑器和 `tests/`，不包含设计 skill。
